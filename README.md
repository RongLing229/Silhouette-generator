Silhouette Block-out Generator
Silhouette Block-out Generator is a browser-based tool for early-stage character concept exploration.
The tool uses controlled procedural generation to create humanoid silhouette variations based on artist-defined settings. It is designed to provide starting points for character ideation rather than finished character designs.
Artists can adjust body proportion, pose, shape language and secondary Accent Shapes, generate multiple variations, keep promising results, reroll the remaining silhouettes, and export the final sheet for paint-over in software such as Adobe Photoshop.
Features
Single Design
Single Design is used to establish the main direction of a silhouette.
Available controls include:
- Circle, Square and Triangle shape-language weighting
- Head, torso, pelvis, shoulder and leg proportions
- Limb variation
- Editable 2D skeleton
- Symmetry
- Contour variation
- Mass bias
- Taper direction
- Accent Shapes
The generated silhouette remains based on a humanoid structure while allowing stylised changes in proportion and contour.
Accent Shapes
Accent Shapes add secondary forms around selected body areas, including:
- Head
- Shoulders
- Elbows
- Knees
Built-in Circle, Square and Triangle accent families are available.
Users can also upload a custom transparent PNG and use it as an Accent Shape.
Accent controls include:
- Scale
- Rotation variation
- Horizontal flipping
- Symmetry
- Additive, Replace and Mixed modes
- Silhouette Break Strength
Silhouette Sheet
Silhouette Sheet is used to generate and compare multiple silhouettes at the same time.
The current Single Design settings are used as the base for the batch.
Users can control:
- Number of silhouettes
- Specified or Randomized generation
- Randomization scope
- Same Pose or Pose Variation
Each generated silhouette receives its own procedural variation.
Keep and Reroll
Useful silhouettes can be marked as kept.
Press Reroll Unlocked to regenerate only the silhouettes that have not been kept.
This allows the artist to gradually build a preferred sheet without losing promising results.
PNG Export
The final silhouette sheet can be exported as a 1920 × 1080 transparent PNG.
The exported image contains solid black silhouettes with a transparent background and does not include interface elements, Keep indicators or selection borders.
How to Use
1. Set up a design
Open Single Design and adjust the main character settings.
Choose the preferred shape language, proportions, pose and Accent Shape options.
2. Generate a silhouette
Press Generate Silhouette to create a result based on the current settings.
Adjust the controls and regenerate until the general direction is suitable.
3. Create a silhouette sheet
Switch to Silhouette Sheet.
Choose the number of silhouettes, variation mode and pose mode, then press Generate Silhouette Sheet.
4. Select promising results
Use the Keep controls to mark silhouettes that you want to preserve.
Press Reroll Unlocked to replace the remaining results.
Repeat this process until you have a useful set of silhouettes.
5. Export
Press Export Sheet PNG to save the current silhouette sheet as a transparent image.
The exported file can then be opened in Photoshop or another drawing application for paint-over and further character development.
